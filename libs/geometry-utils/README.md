# ImagingPipeline Geometry Utils

Common geometry helpers for pipeline services.

- Read WKT into validated 2D NetTopologySuite geometry.
- Read GeoJSON into validated 2D NetTopologySuite geometry.
- Read trusted WKT or GeoJSON as 2D geometry without validity checks for
  already-validated configuration data.
- Write geometry as 2D WKT or GeoJSON.
- Validate geometry is non-empty and valid.
